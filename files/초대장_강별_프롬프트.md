# 초대장 강의 — 강별 프롬프트 모음

> 인프런 「비전공자가 AI로 만든 진짜 서비스」 실습용 프롬프트·명령어 모음입니다.
> 각 코드 블록을 그대로 복사해서 Claude Code 입력창(또는 터미널)에 붙여넣으세요.
> 🧠 표시가 없는 강은 Effort Low로 충분합니다.

**공통 원칙**
- API 키·비밀번호는 코드에 직접 쓰지 않고 `process.env`로 접근, 값은 `wrangler secret put`으로만 등록합니다.
- `.dev.vars` 파일은 만들지 않습니다.
- 이 문서의 가짜 계좌·전화번호·키 값은 모두 테스트용입니다.

## 기본편 9강 — RSVP·방명록 기능 만들기

### 프롬프트

```
"/rsvp" 페이지에 참석 여부 응답과 방명록 기능을 추가해줘.

  보여줘

  만들어줘 — 이름은 "테스트하객1"~"테스트하객8" 형식으로, 참석 5명·
  불참 2명·미정 1명으로 섞어서 구성해줘

### 프롬프트

```
